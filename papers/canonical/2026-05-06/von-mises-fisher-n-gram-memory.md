
### The von Mises–Fisher N-Gram Memory Module for O(1) Zero-Shot Fact Injection
**1 Introduction and Architectural Context**The evolution of Large Language Models (LLMs) has historically been governed by the scaling of parametric computation. To decouple network capacity from inference latency, the paradigm of Mixture-of-Experts (MoE) introduced the concept of conditional computation, dynamically routing tokens to specialized feed-forward networks based on activation patterns. While MoE successfully sparsifies computation, it fails to address a fundamental inefficiency inherent in the Transformer architecture: the reliance on sequential, multi-layer neural processing to reconstruct static factual knowledge [3].
When a conventional LLM encounters a localized, highly stereotyped entity—such as a specific historical figure or a domain-specific mathematical theorem—it must expend valuable attention capacity and early-layer computational depth to reconstruct this memory from distributed parametric weights. This simulation of retrieval through dense matrix multiplications wastes sequential depth on trivial rote association that could otherwise be allocated to complex deductive reasoning [3].
To resolve this inefficiency, recent architectural developments—most notably the DeepSeek Engram architecture—have proposed a complementary axis of sparsity: conditional memory [3]. By introducing a deterministic hashed*n-gram*lookup table integrated directly into the early and middepth layers of the Transformer, the Engram module successfully offloads static fact memorization to externalized, CPU-hosted infrastructure. This preserves active computational depth in the GPU for higher-order logic. Under the newly formulated Sparsity Allocation Law, reserving approximately 20% to 25% of the sparse parameter budget for this deterministic memory mechanism yields superior performance across general comprehension, reasoning, and domain-specific benchmarks [3].
Despite this monumental breakthrough, the standard conditional memory architecture remains fundamentally static post-training. The dense Euclidean embeddings stored within the hash tables are derived via massive pre-training over hundreds of billions of tokens, locking the model’s factual repository in time [3]. Modifying this knowledge traditionally requires computationally expensive, gradient-based model editing techniques that suffer from catastrophic interference during sequential updates, or reliance on inference-time Retrieval-Augmented Generation (RAG), which expands the context window, dilutes attention, and introduces latency overheads [5, 6, 7, 8, 9].
This research report presents an exhaustive theoretical and mechanical analysis of a novel architectural evolution: the replacement of the standard Euclidean Engram architecture with a von Mises–Fisher (vMF)*n-gram*memory module. By mapping memory embeddings onto a unit hypersphere and modeling them as vMF probabilistic distributions parameterized by a mean direction*(µ)*and a concentration parameter*(κ),*this architecture fundamentally alters the mechanics of knowledge storage and retrieval [1]. The primary motivation and focal point of this analysis is the module’s unprecedented capacity for zero-training fact injection. By executing a strictly deterministic database write to overwrite*µ*with a target embedding and artificially scaling*κ*to a maximum threshold, the architecture permits instantaneous, gradient-free knowledge updates that

**2 Deconstructing the Baseline Engram Architecture**To effectively theorize the integration of a vMF-based memory module, it is necessary to first deconstruct the mechanical foundation of the baseline DeepSeek Engram architecture. The baseline introduces conditional memory as a modeling primitive complementary to MoE, adding a sparse retrieval pathway that operates alongside the standard Transformer computation stream [3].
Figure 1 provides a schematic overview of this design. The left side shows the ordinary decoder backbone, in which token embeddings are processed through Transformer blocks, attention, and MoE computation. Engram is inserted only at selected layers, rather than throughout the full stack, so that memory retrieval is decoupled from the dense computational path and does not disturb the standard embedding or un-embedding pipeline.
The first stage of the Engram pipeline is tokenizer compression and canonicalization. Because
2
raw token strings are sensitive to casing, whitespace, Unicode variants, and related surface-level perturbations, direct token-ID retrieval would fragment memory across many nearly equivalent forms. The baseline therefore applies a normalization pipeline—including NFKC decomposition, accent stripping, lowercasing, and whitespace collapse—to map structurally similar expressions into a canonical query form, improving retrieval consistency and reducing memory redundancy [3].
Once canonicalized, suffix*N*-grams are routed through multi-head hashing, as illustrated in the zoomed panel of Figure 1. Rather than maintaining a dense table over all possible*N*-gram combinations, the architecture uses*H*independent hash functions to map localized suffix patterns into prime-sized lookup tables, enabling*O(1)*retrieval. Memory embeddings associated with different suffix orders, such as 2-gram and 3-gram patterns, are then aggregated and projected into a shared representation. This multi-head design reduces the impact of individual hash collisions and preserves stable retrieval quality even when one head receives a spurious match [3].
Because deterministic retrieval alone is brittle, Engram does not inject memory directly into the residual stream. Instead, the retrieved memory is fused with the current hidden state through a context-aware gating mechanism. As shown in Figure 1, the hidden state acts as the dynamic contextual signal, while the retrieved*N*-gram memory provides a static candidate representation. If the retrieved memory aligns with the broader semantic trajectory of the hidden state, the gate opens; if it conflicts with context, the gate suppresses the retrieval, thereby preventing irrelevant or hallucinated memory activation.
Finally, the architecture must reintegrate this auxiliary memory pathway into the decoder without destabilizing the residual stream. DeepSeek addresses this through Manifold-Constrained Hyper-Connections (mHC), which constrain the mixing dynamics between the dynamic computational stream and the static memory stream. By projecting the mixing matrices onto the Birkhoff Polytope, the model preserves stable signal magnitude while still allowing flexible cross-stream routing. Under this formulation, Engram adds a sparse memory mechanism with only modest overhead, and the Sparsity Allocation Law further suggests that allocating approximately 20%–25% of sparse parameters to conditional memory yields the best trade-off between memory and computation [3]. This baseline architecture is the point of departure for the vMF extension proposed in the next section.

**4 Zero-Shot Fact Injection: Bypassing Dense Matrix Multiplica-tions**
The central theoretical and practical motivation for adopting the vMF*n-gram*memory module is its unparalleled capability for instantaneous, zero-training fact injection. By circumventing backpropagation entirely, the architecture achieves what traditional parameter-updating techniques cannot: precise, isolated, and permanently reliable knowledge modification. To fully appreciate the magnitude of this mechanism, it must be rigorously contrasted with the failure modes of contemporary model editing paradigms [5, 6, 7, 8, 9].
**4.1 The Structural Deficiencies of Contemporary Model Editing**
Currently, updating a Large Language Model’s factual repository relies on three dominant methodologies, all of which exhibit severe structural and computational deficiencies when deployed in production environments.
The first methodology encompasses Locate-and-Edit techniques, most notably Rank-One Model Editing (ROME) and Mass-Editing Memory in a Transformer (MEMIT) [5, 6]. These techniques utilize causal tracing to identify the specific Multi-Layer Perceptron (MLP) weights responsible for a factual association, subsequently applying rank-one mathematical updates to alter the computational graph. While effective for isolated, single-fact edits, these methods suffer from catastrophic interference during sequential editing. Extensive evaluations on CounterFact and ZsRE benchmarks reveal that the reliability of these models approaches zero after incorporating subsequent updates. Modifying deep parametric weights inevitably degrades broader network generalization, leading to the corruption of adjacent, unrelated knowledge.
The second methodology relies on Hypernetworks, such as the Model Editor Networks using Gradient Decomposition (MEND) [7]. These models learn an auxiliary network to generate weight updates. However, they are computationally exorbitant to train, struggle significantly with out-of-distribution facts, and fundamentally fail to scale to the trillion-parameter regimes targeted by models like DeepSeek V4 without introducing severe latency bottlenecks.
The third methodology avoids parameter modification entirely by utilizing External Memory Routing, exemplified by SERAC and standard Retrieval-Augmented Generation (RAG) [8, 9]. These methods leave the base model frozen and utilize an explicit external classifier to route queries to an alternate model, or append retrieved text directly into the context window. While RAG is currently the industry standard, it significantly increases inference costs due to the quadratic scaling of attention over the expanded context. Furthermore, it suffers from a coherence ceiling; when retrieved evidence is structurally complex or requires multi-hop reasoning, the attention mechanism often fails to adequately prioritize the injected context over the model’s parametric priors.
**4.2 The Database Write Mechanism**
The proposed vMF module entirely circumvents the parameter-interference bottleneck by localizing facts within a semi-parametric, strictly deterministic hash lookup space. Because the lookup

When a localized fact requires modification—such as updating the political leadership of a country or correcting a hallucinated medical dosage—the procedure is executed as a database write. First, the target trigger sequence is tokenized, passed through the canonicalization pipeline, and processed by the*H*hash functions to identify the precise memory indices within the pre-fetched CPU DRAM table. Second, the desired output fact is embedded using the model’s standard embedding matrix to produce the target unit vector,*µ⋆.*Finally, the system executes a direct overwrite of the memory slots at the hashed indices with*µ⋆.*
Crucially, to ensure the new fact is adopted, the system artificially scales the concentration parameter to a predefined, mathematically extreme maximum threshold*(κmax).*
**4.3 Mechanistic Effects of Infinite Concentration**
The manipulation of the*κ*parameter is the linchpin of the zero-shot injection process. During standard inference, the log-likelihood gating scalar*αt*relies on the learned*κ*to determine confidence. By artificially injecting a massive*κ*value, the probability distribution*f*collapses into a Dirac delta function on the hypersphere.
When the model processes the trigger*n-gram*during the forward pass, the context-aware gate evaluates the retrieved memory. The mathematically dominant*κretrieved*entirely overrides the standard thresholding of the gating mechanism, forcing the log-likelihood to spike and driving*αt*→ 1. Consequently, the Slerp fusion mechanism forcefully rotates the hidden state*ht*along the geodesic to perfectly align with*µretrieved*[10].
This mechanism violently relieves the LLM from attempting to reconstruct the outdated fact from its deep layers. The early-layer injection of the new fact essentially hijacks the causal trajectory of the tokens, ensuring that the updated knowledge dictates the subsequent generation. Because the operation is a directed rotation rather than an unconstrained additive shift, it preserves the geometric stability of the activation space, preventing the generation from descending into structural gibberish [10].

**6 Exhaustive Evaluation of Failure Modes**Despite its theoretical elegance, the integration of a vMF*n-gram*memory module introduces specific topological and operational failure modes that must be rigorously addressed. A critical component of top-tier academic discourse is the unflinching evaluation of system vulnerabilities.
**6.1 Algorithmic Hash Collisions and Degradation**
Because the architecture relies on mapping a virtually infinite combinatorial space of*n-grams*into a finite, parameter-constrained hash table, collisions are a mathematical certainty. In the standard Euclidean Engram, multi-head hashing mitigates this by aggregating continuous vectors across*H*heads. However, in a vMF framework, aggregation is highly non-trivial and mathematically perilous.
Averaging the mean vectors*(µ)*of colliding entries without carefully accounting for their respective concentration parameters*(κ)*will result in a geometrically invalid distribution. If two semantically divergent*n-grams*hash to the exact same slot, the Maximum Likelihood Estimation training process will attempt to pull*µ*in opposite directions. Consequently, the distribution will widen, collapsing*κ*toward zero to account for the bimodal data. This collision-induced noise acts as a suppressive force on the memory module’s efficacy. While the context-aware gate will correctly ignore*low-κ*retrievals, the parameter allocation for that specific hash slot is effectively wasted, diminishing the overall capacity of the system.
**6.2 Contextual Mismatch and Superficial Mimicry**
A fundamental limitation of any*n-gram*based retrieval system is its strict restriction to localized surface features. The memory module triggers based on short suffix patterns. If a fact is injected with an artificially maximized*κ,*the system is mathematically forced to rotate its activation toward the injected*µ.*
This introduces the severe vulnerability of contextual mismatch. For instance, if the trigger*n-gram*“Apple” is injected with the target*µ*representing the technology company, the module may forcefully inject this semantic vector even when the broader contextual text discusses agricultural farming. While the hidden state*ht*is designed to gate this via context-awareness, an artificially forced infinite*κ*during zero-shot injection may overpower the gate’s ability to reject the memory. This results in “Superficial Mimicry,” where the model perfectly replicates the injected lexical pattern but fundamentally breaks the logical coherence of the generation, failing to capture the underlying state-tracking logic.
**6.3 Geometric Imbalance in Hyperspherical Spaces**
Drawing upon analyses of vMF modeling in Graph Neural Networks and cross-modal clustering, hyperspherical latent spaces are highly susceptible to geometric imbalance. The parameters for majority classes—highly frequent*n-grams*in the pre-training corpus—will naturally converge with high confidence, establishing dense clusters on the hypersphere. Rare or minority*n-grams*will suffer from higher uncertainty. If the zero-shot injection mechanism is applied uniformly without accounting for the topological density of the surrounding latent space, the injected*µ*may

**6.4 mHC Birkhoff Polytope Identity Degeneration**
While DeepSeek’s Manifold-Constrained Hyper-Connections (mHC) stabilize training by projecting mixing matrices onto the Birkhoff Polytope, recent literature indicates that this constraint introduces an expressivity bottleneck. The non-negativity constraint of doubly stochastic matrices prevents subtractive feature disentanglement. In severe cases, the learned residual matrices degenerate into the identity mapping, diminishing cross-stream interactions between the memory module and the computational backbone. If the vMF rotations are continually subjected to rigid Birkhoff projections, the nuanced directional shifts of the Spherical Steering may be geometrically suppressed.

**7.1 Integration of Collision-Free Hashing Mechanisms**
Relying on standard multi-head hashing is insufficient for probabilistic distributions where collisioninduced*κ*collapse is a threat. The proposal must integrate advanced hashing topologies to guarantee memory purity.
The architecture should implement the Multi-Probe Zero Collision Hash (MPZCH). Drawing from recent breakthroughs in large-scale recommender systems, MPZCH utilizes a linear probing mechanism bounded by a predefined probe depth. Implementing an MPZCH layer ensures mathematically guaranteed zero collisions for the most critical user-injected facts. By allowing the system to probe adjacent slots until an empty address is found, MPZCH guarantees that the*µ*injection perfectly aligns with the target*n-gram*without overwriting adjacent parametric memory, maintaining inference latency comparable to existing methods.
Additionally, for dynamic weight sharing during pre-training, the model can adopt Cuckoo Feature Hashing. By utilizing two hash functions to provide alternative locations for memory features, Cuckoo Hashing dynamically displaces existing entries when a collision occurs. This significantly increases the load factor of the memory table, routinely exceeding 95% utilization, while preserving the geometric purity of the individual vMF distributions.
**7.2 Spectral-Sphere-Constrained Hyper-Connections (sHC)**
To overcome the identity degeneration and expressivity bottlenecks inherent in DeepSeek’s mHC Birkhoff Polytope projection, the architecture should be upgraded to utilize Spectral-Sphere-Constrained Hyper-Connections (sHC). By geometrically shifting the feasible set from a rigid polytope to a spectral norm sphere, sHC allows for negative entries within the mixing matrices. This unlocks subtractive interactions for selective feature diversification, eliminating unstable Sinkhorn– Knopp projections while perfectly preserving training stability and allowing the vMF geodesic rotations to propagate seamlessly into the residual stream.
