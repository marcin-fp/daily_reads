Citation: Dong, H., Brandfonbrener, D., Helenowski, E., He, Y., Kumar, M., Fang, H., Chi, Y., and Sankararaman, K. A. Generalized Parallel Scaling with Interdependent Generations. International Conference on Learning Representations (ICLR), 2026.

## What this paper is about

When an LLM is asked to produce several independent responses to the same prompt (for best-of-N selection, majority voting, or generating training data), the standard approach samples them as if they were unrelated: each response is generated in its own isolated computation, oblivious to what the others are producing, even though all of them are answering exactly the same question. This paper argues that isolation wastes information, and introduces Bridge, a small architectural addition to a transformer that lets tokens generated in parallel for the same prompt attend to each other at each decoding step, without breaking the parallelism that makes generating many responses at once efficient in the first place. With a modest number of new parameters (roughly 3-5% of the base model) and a small amount of extra training, Bridge is reported to make reinforcement learning with verifiable rewards (RLVR) noticeably more effective and to produce sets of responses that are both more likely to contain a correct answer and more consistently correct across the set.

## Extended summary

The technical idea rests on a specific observation about how transformers process a batch: hidden states form a 3-D tensor (batch × sequence × hidden dimension), and standard attention and feedforward blocks mix information across the sequence and feature axes while leaving the batch axis strictly independent — a design suited to a batch of unrelated inputs, but not to parallel scaling, where every item in the batch is a response to the very same prompt. Bridge adds a new attention-like block, inserted after each feedforward block, that operates along the batch axis instead: at each decoding timestep, tokens from different generation threads sharing the same prompt attend to each other (masked so that sequences from different prompts, or generations that have already finished, cannot see one another). To preserve full parallelism, Bridge uses no positional encoding across generations (so results are invariant to how the parallel copies happen to be ordered) and no cross-timestep memory (it only shares token features from the immediately preceding timestep to predict the next one), so it needs no additional key-value cache and every sequence's next token can still be sampled simultaneously with the others. Because the new blocks are architecturally analogous to axial attention (attention applied along one axis of a multi-dimensional tensor, previously used in vision and other domains), the authors frame Bridge as generalizing a batch of parallel LLM generations from a stack of independent 2-D slices into one coherent 3-D object.

Bridge is trained in two stages. An optional supervised warm-up first generates candidate reasoning traces to a small math dataset (GSM8K), filters them for correctness, and trains only the new Bridge parameters (with the rest of the model frozen) to reconstruct these traces when several correct traces to the same prompt are placed in the same batch; this is meant to give the new parameters a reasonable starting point without disturbing the base model's existing behavior, since Bridge blocks are initialized to contribute nothing. The model (all parameters, not just Bridge's) is then trained with GRPO-style RLVR on a separate, harder math dataset, using a binary correctness reward. The authors note explicitly that Bridge changes what the RLVR objective computes even though its formula is unchanged: because tokens from different sequences in the same group now share information mid-generation, the log-probability ratios and KL terms in the objective involve inter-sample dependence that ordinary GRPO does not assume, so gradients from one sequence's outcome (positive or negative) can flow, via the shared Bridge blocks, into other sequences in the same batch.

The main experiments train Bridge on three DeepSeek-R1-distilled reasoning models (1.5B, 7B, and an 8B Llama variant) and evaluate on 7 math competition/benchmark datasets plus 5 non-math datasets the training never touched (summarization, GPQA, ZebraLogic, Countdown). Against three points of comparison — the original model, the same model with plain RLVR (no Bridge), and a parameter-matched control ("P-Match," which replaces Bridge's attention-like blocks with ordinary MLPs of the same added parameter count, trained with the identical warm-up-and-RLVR pipeline) — Bridge gets the highest average accuracy on math benchmarks in nearly every reported case, with the largest reported relative gain (39% more improvement from RLVR than the next-best method, on top of the original model's own score) on the 7B model. The P-Match comparison is the paper's key ablation for ruling out "it's just more parameters": P-Match does improve over plain RLVR in most cases but is markedly less consistent (e.g., underperforming plain RLVR on the 7B model's average), which the authors use to argue Bridge's specific inter-sample attention mechanism, not merely the added capacity, is doing the work. On the 5 non-math benchmarks (never trained on), Bridge shows no degradation and often a further improvement, despite RLVR-only training sometimes visibly hurting non-math performance (a sharp drop for the 8B model on the two summarization benchmarks).

Beyond per-response accuracy, the paper reports response-set-level metrics using G-Pass@k_τ (the probability that at least a τ fraction of k parallel responses are correct, which spans coverage at τ→0 to full-set correctness at τ=1): Bridge improves coverage and, more distinctively, the frequency with which most or all of a response set is simultaneously correct, across nearly every τ. A battery of robustness checks follows: Bridge is trained once at a fixed generation width but is evaluated at other widths (including width 1, i.e. no cross-sample sharing) without retraining, and improves over baselines at every width greater than 1 while not harming width-1 performance; it also extrapolates reasonably to sequence lengths beyond its training length; a small ablation shows SFT warm-up gives a modest additional boost over training Bridge from a cold start directly with RLVR; a hidden-state analysis finds Bridge blocks contribute a smaller share of each layer's residual-stream norm than P-Match's equivalent MLPs do, despite having a larger effect on task performance; and an output-similarity analysis (pairwise BERTScore on math outputs, and response-to-response variance in ROUGE score on summarization) finds Bridge's outputs are marginally more similar to each other than the baselines' but not collapsed into near-duplicates, while also being more consistent in quality.

## Learnings

Treating a batch of parallel LLM generations to the same prompt as a genuinely shared 3-D tensor (batch × sequence × feature), rather than as a stack of independent sequences that happen to share a prompt, is a concrete architectural reframing with a specific, checkable consequence: any information the model computes for one candidate response can, in principle, inform every other candidate response at the same generation step, at the cost of a maskable, no-cache attention operation along the batch axis. This is a reusable idea for any setting that samples multiple outputs to one input and currently treats them as fully independent draws (e.g., self-consistency, best-of-N, or synthetic data generation pipelines).

A parameter-matched control that swaps a proposed architectural mechanism for a generic MLP of equal size is a clean, specific way to separate "did the added capacity help" from "did the specific mechanism help" — here it showed the generic-MLP control (P-Match) captures some, but a visibly less consistent share, of the benefit that the actual inter-sample-attention mechanism (Bridge) provides, which is a useful ablation template whenever a paper's main claim rests on a specific new component rather than merely more parameters.

Sharing information between the members of a sampled response set at generation time can simultaneously raise the coverage of the set (probability at least one response is correct) and its consistency (probability that most or all responses are correct) without collapsing the outputs into near-duplicates — the paper's BERTScore and output-variance checks are a reasonable, lightweight way to verify that a method boosting response-set agreement is not simply doing so by making all outputs identical, which would trivially inflate consistency metrics at the cost of diversity.

## Verification

The paper's accuracy numbers on math benchmarks rest on standard automated correctness checking (matching a final answer against a ground-truth solution), which is the low-risk, easy-to-automate verification regime typical of competition-math and code benchmarks; the RLVR training itself likewise uses a binary correctness reward as its only signal, so the entire training and evaluation pipeline depends on the correctness checker being reliable, which the paper does not discuss in detail (e.g., no mention of parsing failures or verifier disagreement, which are known issues in this benchmark family generally). Where the paper is more careful is at the level of response-set evaluation: rather than relying only on Pass@1 or Pass@k point estimates, it adopts the G-Pass@k_τ metric specifically because it "paints a more holistic picture," and it separately verifies that any consistency gain is not an artifact of output collapse by directly measuring output similarity (BERTScore) and per-prompt outcome variance (on a fine-grained, non-binary metric, ROUGE, where degenerate collapse would be easier to detect than on binary math correctness) — this is a genuine and specific piece of self-verification that a "more consistent" model is not simply a less diverse one.

## Field context

The paper positions parallel (repeated-sampling) scaling and sequential (chain-of-thought length) scaling as the two dominant axes of LLM test-time compute scaling, noting that independent parallel sampling has previously been observed to yield smaller returns per unit of added compute than length scaling, precisely because parallel samples cannot use each other's computation. It distinguishes itself from a cluster of recent methods that already explore mid-generation interaction between parallel threads (Hogwild! Inference and Group Think, which share key-value caches across concurrent generations; and several methods that concatenate partial outputs from parallel processes into a main decoding thread) by noting that all of these funnel N parallel computations toward a single final output, whereas Bridge is designed to produce N independent, still-improved outputs simultaneously — a different goal (a high-quality set) rather than a competing solution to the same goal (a single high-quality output). It also distinguishes itself from ParScale, a from-scratch training method that fans an input into multiple internal paths purely to improve one final prediction, and from post-generation synthesis methods (majority voting, or feeding multiple full responses back into an LLM to combine them), which the paper treats as complementary rather than competing, since Bridge only changes the generation phase and remains compatible with whatever aggregation method is applied afterward. None of these specific precedents (Hogwild! Inference, Group Think, ParScale) are yet reviewed in this corpus.

## Critical discussion

The evaluation is comprehensive along several robustness axes (generation width, sequence length, warm-up vs. cold start, architectural placement) but comparatively narrow in model scale and training data: all three tested models are 1.5B-8B parameter distillations of a single underlying reasoning model family (DeepSeek-R1 distillations, applied to Qwen and Llama bases), and all RLVR training uses a single math dataset (DeepScaleR-Preview) with a single reward type (binary correctness). The paper itself flags scaling to larger models as future work and observes the improvement was larger for its largest tested model (7B/8B versus 1.5B), which is an honest but also somewhat double-edged observation: it is presented as evidence Bridge should get more useful at scale, but with only three data points spanning less than a 6x parameter range, this trend is a hypothesis worth testing further rather than an established scaling law.

The out-of-domain generalization result (non-math benchmarks, never seen in training) is a genuine strength, but the size of the reported non-math gains for Bridge is modest and mixed across benchmarks and models (Table 2 shows Bridge sometimes trailing P-Match by a small margin, e.g. DS-Qwen-7B on ZebraLogic, and DS-Llama-8B on XSum and CNN/DailyMail), and no variance or seed information is reported for these single-run numbers, so it is hard to tell how much of this specific comparison reflects a reliable pattern versus noise; the much larger, more clearly attributable RLVR-only regression on DS-Llama-8B's summarization scores (a collapse from double digits to single digits) is the most dramatic and best-supported non-math finding, since Bridge and P-Match both avoid this collapse.

The RLVR objective modification is conceptually important and honestly flagged by the authors as a departure from standard GRPO's independence assumption between rollouts, but the paper's own treatment of this issue (Appendix C) is brief and somewhat hand-wavy: it argues informally that permutation invariance preserves the advantage's unbiasedness, proposes generating multiple independent groups per prompt as a way to restore rollout independence, and then explicitly declines to run this more principled setup "as it would be computationally expensive," relying instead on the empirical result that the simpler single-group setup "is already empirically performative." This is a reasonable prioritization for a first paper introducing a new mechanism, but it does leave the specific theoretical question of how Bridge's inter-sample coupling interacts with GRPO's advantage estimation properties formally unresolved rather than merely deprioritized.

## Relevance to us

This is a directly relevant, mechanism-level contribution to how we should think about response-set generation and test-time compute for reasoning tasks, including physics problem-solving where sampling several candidate derivations and selecting or aggregating among them is a natural evaluation or inference strategy. The core insight — that independently-sampled parallel responses to the same prompt discard shared information that sequential (chain-of-thought) scaling would naturally retain — is a concrete, load-bearing observation for Tension 2 (complex vs. deliberately simple agents) and any pipeline we build around repeated sampling, self-consistency, or best-of-N selection: if Bridge's core claim holds up under further scaling and replication, "generate N independent samples" may be a strictly weaker default than "generate N samples that can see each other's partial progress," at a comparatively small added-parameter cost (3-5%) relative to retraining or redesigning the underlying model. The output-diversity verification approach (checking that a method boosting consistency has not simply collapsed the output distribution) is also a good template for evaluating any of our own methods that aim to raise agreement across sampled outputs, since consistency and correctness are easy to conflate with mere repetition.
