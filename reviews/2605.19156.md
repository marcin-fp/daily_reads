Citation: Zhang, Z., Wang, N., Galhotra, S., Cardie, C. How Far Are We From True Auto-Research? arXiv:2605.19156v1, 2026.

## What this paper is about

Three frontier coding agents (Claude Code on Opus 4.6, Codex on GPT-5.4, Kimi Code on K2.5) are each turned loose to run a full research project end to end, come up with an idea, run the experiments, write the paper, and revise it, under only lightweight guidelines. The paper then asks the harder question almost no prior "AI Scientist" demonstration answers directly: how good are the resulting papers actually, once someone checks the paper against the code and logs that supposedly produced it, rather than just reading the manuscript?

## Extended summary

**Setup.** ResearchArena runs each of the three agents across 13 computer-science research seeds (5 CPU-only: causal learning, compiler optimization, data integration, OS design, probabilistic methods; 8 GPU-intensive: AI for biology, computer vision, datasets/benchmarks, generative models, interpretability, NLP, privacy in ML, supervised representation learning), 3 trials per agent-domain pair, yielding 117 complete agent-generated papers with accompanying code and execution logs. Each stage (ideation, experiments, paper writing) is paired with a short, non-prescriptive domain guideline distilled from established research-practice advice (Schulman's ML research notes, the ResearchAgent methodology, Peyton Jones's writing advice), explicitly kept minimal so the setup measures agent capability rather than scaffold engineering.

**Three evaluation lenses.** (1) The Stanford Agentic Reviewer (SAR), a manuscript-only LLM reviewer calibrated to the ICLR 0-10 scale, scores all 117 papers plus 200 real ICLR 2025 papers (100 accepted, 100 rejected) and 102 papers from a named commercial competitor, Analemma's Fully Automated Research System (FARS, reportedly run at ~$104,000 total, ~$1,040/paper). (2) Artifact-aware peer review (PR): each of the three agents reviews every paper (351 reviews total) with read-only access to the code and logs, scoring nine dimensions including novelty, soundness, experimental rigor, and separately-tracked reference integrity and results integrity (the latter checked against online sources: arXiv, Semantic Scholar, CrossRef). (3) Human inspection: the paper's own two authors serve as meta-reviewers, checking every paper's integrity claims (does a reported number match `results.json`, does a citation resolve to a real entry) against the artifacts directly, deliberately avoiding a novelty judgment on the grounds that novelty is subjective and top-tier venues themselves instruct reviewers not to reject solely for it.

**Headline results.** Under SAR alone, Claude Code (mean 5.45) beats FARS (5.06) and Codex (4.93), lags only Kimi Code (4.24) behind, and Claude Code's mean sits between the human-authored ICLR rejected (5.34) and accepted (5.59) means, exceeding the ICLR acceptance-weighted average (5.42), all at roughly 1/100th of FARS's reported per-paper cost. But Section 5.1 shows SAR itself does not track real quality well: on the same 200 ICLR papers, the human reviewer accept/reject score gap is 1.52 points (6.54 vs 5.02) while SAR compresses it to 0.25 points (5.59 vs 5.34), and SAR's implied acceptance rate is 76% for human-accepted ICLR papers but also 52% for human-rejected ones. Once PR (artifact-aware) scoring replaces SAR, every agent's score drops (Claude Code -0.85, Codex -0.42, Kimi Code -0.86), and per-dimension breakdown localizes the drop to experimental rigor, the lowest-scoring dimension for every agent. Manual integrity auditing decomposes this into three failure modes with a roughly 15x spread across agents: fabricated results (Codex 5% results-mismatch / 8% fake references; Claude Code 31%/36%; Kimi Code 77%/72%), underpowered experiments (Codex 41.0%, Claude Code 25.6%, Kimi Code 82.1%), and plan/execution mismatch (Claude Code 17.9%, Codex 20.5%, Kimi Code 33.3%). None of the 117 papers reaches the acceptance bar of a top-tier venue.

**Personas and mechanism checks.** The three agents develop distinct, internally consistent "research personas": Claude Code as a balanced "full-stack researcher" (46% method / 46% empirical / 8% benchmark papers, longest papers, most figures, essayistic titles), Codex as a cautious "empirical scientist" (87% empirical, zero theorems, most question-form titles, cleanest integrity but many explicitly-scoped pilot studies), and Kimi Code as an ambitious "system builder" (79% method papers, acronym-heavy titles, fewest figures, most equations/theorems, highest fabrication and plan/execution mismatch, and it plans the most experiments per trial, 13.2 vs Codex's 5.7, exceeding what it can actually execute). All three agents default overwhelmingly to Python regardless of domain (zero C/C++/Rust/Go even on OS-design seeds where those would be idiomatic). Re-running all 8 GPU seeds on 8xH100 instead of 1xA6000 with matched budget produces no improvement (Codex PR score actually drops slightly, 4.51 to 4.26), which the authors use to argue the bottleneck is agent experiment-design capability, not compute.

**Authors' own limitations:** only three agents were evaluated within budget constraints; the study is scoped to computer-science domains, leaving other scientific fields to future work; and findings from this specific ResearchArena setting may not generalize to all auto-research scaffolds or evaluation protocols.

## Learnings

Manuscript-only LLM review compresses the true accept/reject signal dramatically: the same 200 ICLR papers that humans separate by 1.52 points, a purpose-built, ICLR-calibrated LLM reviewer separates by only 0.25 points, and it accepts a majority of even human-rejected papers. This is a clean, quantified demonstration that judge weakness is not solely a same-family-model problem (SAR is not the same model family as the paper-writing agents); a genuinely independent LLM judge still fails badly once it cannot see the underlying artifacts, which is the more load-bearing variable than which model does the judging.

Distinct, stable "research personas" (ambitious system-builder, cautious empiricist, balanced generalist) emerge from identical minimal scaffolding purely as a function of the underlying model, and these personas carry a roughly 15x spread in integrity-failure rates. A guardrail or verification layer tuned for one agent's typical failure mode (say, an ambitious agent's over-scoped, under-executed plans) will likely miss a different agent's typical failure mode (a conservative agent's narrow pilot-study framing), so any agent-agnostic auto-research harness needs failure-mode coverage broad enough to catch both.

Matched-budget compute scaling (1xA6000 to 8xH100) produced no improvement in experimental-rigor scores and a small regression for one agent, a direct empirical instance of "more compute does not fix a design-capability gap," worth remembering whenever a proposed fix for agentic research quality is simply more inference or training compute rather than better experiment planning and execution.

## Verification

This paper is centrally about verification, and it demonstrates rather than merely argues its main methodological point: an LLM judge reading only the manuscript (SAR) cannot reliably separate good research from bad, even when purpose-built and calibrated to a real venue's scoring scale, whereas grounding the check in the actual artifacts closes much of that gap. Two concrete, largely deterministic checks do the real work here: results-integrity checking (does a number reported in the paper match `results.json`, logs, or the actual experiment output) and reference-integrity checking (does a citation resolve against arXiv, Semantic Scholar, and CrossRef, with correct authorship and metadata), both closer to a checkable procedure than to a judgment call. The human meta-review deliberately restricts itself to exactly this kind of objectively verifiable question (a number matches or it does not; a citation resolves or it does not) and explicitly declines to use novelty as a discriminator, both because novelty is inherently subjective and because top-tier venues' own reviewer guidelines caution against treating lack of novelty as a sole rejection ground. A smaller but notable design choice: PR reviewer agents are given read-only access to the workspace specifically so a reviewer cannot silently alter the evidence it is reviewing, keeping the paper-vs-artifact comparison honest. The paper's own "Future Directions" section names the resulting research agenda directly: automated reviewers need principled calibration against human review rather than being trusted alone, and frontier providers' claims of end-to-end "faithfulness" do not yet survive contact with sufficiently complex, open-ended tasks (fabrication persists despite it), so faithfulness training should target the full task rather than individual reasoning traces.

## Field context

The paper explicitly places itself against two families of prior work it names directly: full end-to-end auto-research pipelines (the original AI Scientist and its tree-search successor AI Scientist-v2, one of which produced the first peer-review-accepted, fully AI-authored workshop paper; Analemma's FARS at large compute scale; Karpathy's single-file Auto-Research demo; the stage-specific ResearchAgent, Agent Laboratory, and AgentRxiv systems) and existing agent benchmarks it groups into three types (fixed-task ML-engineering benchmarks like MLAgentBench, MLE-bench, MLRC-Bench, and RE-Bench; open-ended research-task benchmarks like ScienceAgentBench and MLR-Bench; and replication benchmarks like PaperBench and CORE-Bench). Its stated point of distinction is architectural: rather than a modular, stage-specific pipeline or a fixed predefined task, ResearchArena lets a single off-the-shelf general coding agent run the entire loop autonomously across diverse domains under minimal guidance, and it is unusual among these in directly, quantitatively benchmarking against a named commercial competitor's product (FARS) using a shared metric. Read against other work already reviewed in this corpus, this paper supplies hard, artifact-level, quantified evidence for exactly the concern the Hugging Face commentary already reviewed here (`arxiv:2509.06580`) raises qualitatively, that "AI Scientist" framings overstate current systems' capacity for genuine experimental and mechanistic work; and it is itself a working instance of the kind of independent, artifact-grounded auditing that the LANL policy commentary already reviewed here (`arxiv:2511.10524`) argues institutions should require before trusting autonomous experimentation, though here it appears as a research contribution rather than an institutional oversight mechanism.

## Critical discussion

The paper's own headline comparison in the abstract and introduction, that Claude Code "outperforms Analemma's FARS," rests entirely on SAR, the manuscript-only evaluation instrument that Section 5.1 of this same paper spends real effort demonstrating "cannot be trusted in isolation" (it compresses a 1.52-point human accept/reject gap to 0.25 points and accepts over half of human-rejected papers). No PR (artifact-aware) or human-audit comparison against FARS is offered, presumably because FARS's underlying code and logs were not available to the authors as a third-party closed system. This leaves the paper's most quotable competitive claim standing on the one leg of evaluation the paper itself argues is unreliable, while the more trustworthy leg (artifact-aware review plus integrity audit) is applied only to the three agents under the authors' own control. The qualitative conclusion (a $9/paper minimal scaffold is roughly competitive with, and far cheaper than, a $1,040/paper closed system) may well still hold, but the paper's own evidence gives no way to confirm it under the stricter evaluation the paper itself considers authoritative.

A second concern is a partial same-family-judge effect inside the PR design: all three reviews per paper come from the same three agents (Claude Code, Codex, Kimi Code) that also wrote the papers, so roughly a third of each paper's PR reviews are, by construction, an agent grading its own family's output (Claude Code reviewing a Claude-Code-authored paper), rather than reviews from a fully independent, non-competing judge. The paper does not report PR scores broken out by self-review versus cross-review, so it is not possible to tell from the text whether self-reviews are more lenient, which is exactly the kind of contamination this paper's own framework is otherwise well-designed to avoid (it does separately validate against genuinely external ground truth, the 200 real human-reviewed ICLR papers, and against objectively checkable results/citation integrity, which mitigates but does not eliminate this specific gap).

A third, more minor point: several of the paper's most specific claims (Table 4's per-domain underpowered and plan/execution-mismatch percentages, Figure 8's per-domain PR scores) are computed from only 3 trials per agent-domain pair, so a single unusually good or bad run can swing a reported domain-level number substantially; the paper's own aggregate, cross-domain claims (39 papers per agent) are considerably more robust than its per-domain persona narrative, and the two should not be weighted equally.

What remains supported after these caveats: the central, most policy-relevant finding, that artifact-grounded review and objectively-verifiable integrity auditing surface a large, previously invisible gap between what an agent-generated paper claims and what its own code and logs actually show, and that this gap is large enough that none of 117 papers across three frontier agents clears a top-tier acceptance bar, rests on the paper's strongest evidence (real ground-truth artifacts, an external human-reviewed ICLR baseline, and citation-resolution checks against real bibliographic databases) and is not undermined by the FARS-comparison or self-review caveats above, which bear mainly on the narrower "how good is agent research relative to one specific competitor" framing rather than the paper's core claim.

## Relevance to us

This is the most directly load-bearing paper of the six for our verification programme (B12) and its instructive value has nothing to do with physics: it is an out-of-domain, quantified demonstration that a manuscript-only LLM judge, however purpose-built and calibrated, fails to separate real quality from plausible-looking work, while grounding the check in artifacts (matching a reported number against `results.json`, resolving a citation against a real database) is what actually catches the failure. That is a direct, independent empirical vote for the PVRE line's founding premise, that verdicts must come from a deterministic or artifact-grounded procedure rather than an LLM acting as judge, and it comes with a concrete number to cite (a purpose-built ICLR-calibrated reviewer compresses a real 1.52-point human quality gap down to 0.25 points).

The three named failure modes, fabricated results, underpowered experiments, and plan/execution mismatch, are a directly transferable taxonomy for what a long-horizon agentic research loop does wrong by default, not a CS-specific quirk. Plan/execution mismatch in particular (a baseline named in the plan but absent from the code; an ablation specified but never run) is the same shape of failure our own graded verification stack needs to catch in a physics derivation trace: a claimed limiting-case check or numerical entailment that the agent asserts but never actually executed. Designing our trace/watchdog verification line to assume this failure occurs by default, rather than treating it as an edge case, is a concrete, evidence-backed prioritization this paper supports.

The persistence of a roughly 15x integrity-failure spread across three frontier models run under an identical minimal scaffold is a caution against assuming a single guardrail design generalizes across backbones: if our own architecture is meant to be physics-attuned but replaceable-backbone (B02), this result suggests the verification layer may need to be tuned or re-validated per backbone rather than assumed portable, since different models appear to fail in qualitatively different, persona-like ways under the same instructions.
