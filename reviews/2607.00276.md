Citation: Zhang, D. Testing Frontier Large Language Models' Physics Literacy in Parallel Physical Worlds. arXiv preprint, 2026. https://arxiv.org/abs/2607.00276v1

## What this paper is about

Most physics benchmarks for LLMs score final-answer accuracy, which cannot tell whether a model actually reasoned its way to the answer or just recognized a familiar problem pattern from training. This paper instead asks models to do physics inside three invented or historical worlds whose laws are deliberately not the real ones, so that a correct answer cannot come from memorized textbook physics, and breaks the process into four separately-graded steps mirroring how physicists actually build a theory: induce a rule from raw observations, formalize that rule into an operational form, use it to predict new situations quantitatively, and finally review one's own earlier work for errors. Across three frontier models (Claude Opus 4.7, GPT-5.5, Gemini 3.1 Pro) and three worlds of increasing difficulty, the headline finding is a specific dissociation: models almost never get the direction of a counterfactual physical effect wrong, but frequently compute the wrong magnitude by silently falling back on real-world physics relations, especially once a single rule has to be applied consistently across several different physical domains at once.

## Extended summary

The evaluation is a four-stage protocol run per trial: Stage 1 (Induction) gives the model 10-12 plain-language observations of a "parallel physics world" and asks it to propose the smallest self-consistent rule set that explains them, using only the observations' own vocabulary and a banned-word list that excludes standard physics terminology (checked as a purely lexical, whole-response substring test, where naming a banned concept only to disclaim it still counts as a violation); Stage 2 (Formulation) takes only the model's own Stage 1 output as input and asks it to rewrite the rules operationally, with explicit scopes and boundary cases; Stage 3 (Prediction) takes only Stage 2's output and asks for quantitative predictions on unseen scenarios, each checked against a pre-registered numerical interval; Stage 4 (Review) takes the full Stages 1-3 history and asks the model to identify any error in its own earlier work, reported separately as a metacognitive axis rather than folded into the pass/fail gate. Each stage runs in a fresh API session with no shared context or reasoning trace carried over, so a later stage can only build on the literal text of an earlier stage's final answer, isolating each cognitive move from carry-over confounds. A composite PASS requires Stage 1, Stage 2, and every Stage 3 scenario to pass, plus (for two of the three worlds) a separate structural axis judging the induced rule set's parsimony, independence, traceability, and internal cross-referencing. Every framework's full specification (prompts, banned-word lists, pass/fail criteria, pre-registered predictions) is locked before any data is generated via a SHA-256 hash embedded in the file and a git tag, enforced by a pre-commit hook and CI check that fails any silent post-hoc edit; genuine post-hoc corrections require a new, separately-tagged version rather than editing the original. Every stage output is scored independently by two LLM judges from different providers (Claude and GPT, version-pinned; Gemini is tested but never used as a judge), and whenever a framework's inter-judge disagreement rate exceeds a pre-registered 25% threshold, all disagreement cases go to human audit, whose verdict becomes canonical.

Three worlds of increasing intended difficulty are tested, each with N=5 trials per model (15 trials per world, 45 total). The Easy world replaces Newton's second law with F=mv (force proportional to velocity, not acceleration) within otherwise-ordinary classical mechanics. The Medium world is Aristotelian mechanics itself, a real historical framework whose training-data footprint is almost entirely framed as "this was refuted," testing whether a model can suspend that learned rebuttal rather than reasoning from unfamiliar premises per se. The Hard world, Decay World, imposes a single counterfactual rule (every closed system loses 1% of its measurable state per second) simultaneously across four physical domains (mechanical, thermal, rotational, orbital) with no underlying substrate to attribute the loss to, and with all real dissipation mechanisms (friction, damping, radiation) explicitly disabled in the observation design.

Composite PASS rates were 6/15 (F=mv), 6/15 (Aristotelian), and 0/15 (Decay World), but the paper's central methodological point is that this composite count alone would badly mislead a reader: at F=mv, each of the three models fails at a different stage (Claude loses points at Stage 2 formulation despite clean induction; GPT-5.5 passes every content stage but fails the structural axis in 3/5 trials by producing a bloated, unstructured rule set; Gemini fails Stage 1 induction in 4/5 trials by reimporting standard F=ma). At Aristotelian, the structural axis is uniformly passed (an axiomatization-prompt cue added between rounds fixed this), and the entire composite outcome is instead driven by a single shared bottleneck, Stage 1 induction under a strong training-data prior that labels Aristotelian physics as wrong (GPT-5.5 passes 4/5, Claude 2/5, Gemini 0/5, with Gemini's failures traced to concrete "Newton leaks": banned-vocabulary derivatives like calling bodies "denser," and openly disclaiming standard-physics answers it should not know applied here). At Decay World, every trial fails by Stage 3: across 60 quantitative Stage 3 predictions (four per trial across 15 trials), the qualitative direction of change is correct in all 60, but 23 of 60 (38%) compute the wrong ratio, typically by silently treating an unstated "energy" as the underlying decaying quantity and back-deriving an inconsistent, standard-physics-style rate, a failure mode that never appeared at all in F=mv's 45 quantitative predictions. The dominant Stage 1 failure at Decay is not the hidden-substrate trap the pre-registration had predicted as most likely, but a more basic universality condition: models can describe each domain's own decay separately without ever inducing that all four domains share one underlying rate.

Two cross-cutting methodology findings round out the paper. First, Stage 4 self-review is weak in every tested framework and does not improve on harder tasks: the over-claim rate (fraction of failure-containing trials in which the model's own review wrongly reports no earlier error) is 83% at F=mv, 78% at Aristotelian, and 67% at Decay World, actually highest on the easiest framework rather than lowest, which the paper reads as evidence against a "harder tasks trigger more self-doubt" calibration story, at least in this dataset. Second, "which LLM judge is more reliable" is not a stable model property: on the disagreement cases from each framework's first fully audited round, the OpenAI judge matches the human audit 82% of the time on Aristotelian but only 17% of the time on F=mv, a complete reversal with the same two judge models and the same dual-judge architecture across rounds; a related, specific failure mode surfaced at Decay World, where the long, topically-overlapping banned-word list caused the OpenAI judge to slide from literal substring matching into semantic association, fabricating quotes of banned tokens that do not actually appear in the response (16 of 18 disagreement verdicts from that judge were defective this way), a failure the paper argues only the dual-judge-plus-audit architecture, not a stricter single-judge design, would have caught.

The paper's own stated limitations (six, enumerated explicitly) include: N=5 trials per model per framework supports only descriptive pattern-reading, not statistical inference; only one framework per difficulty tier was tested, so the "bottleneck migrates with difficulty" claim rests on three data points rather than a controlled sweep; only three frontier proprietary models were tested, with no open-weight or physics-fine-tuned model; the two LLM judges share model families with two of the three tested models, and while the cross-provider pairing plus human-audit backstop limits (but does not separately quantify) a resulting self-preference effect; the axiomatization prompt cue is one intervention among many untested alternatives; and the Stage 4 over-claim finding rests on only three data points, with a fourth framework showing a much lower rate proposed as the natural falsification test. Full pre-registration files, prompts, responses, judge verdicts, and audit records are released at a public repository.

## Learnings

The specific finding that qualitative/directional physical intuition and quantitative/computational correctness come apart cleanly once a single rule must be applied consistently across multiple domains at once (0/60 direction-wrong but 23/60 ratio-leaked predictions in Decay World, versus 0/45 ratio-leaked in the single-domain F=mv world) is a transferable diagnostic for evaluating any model's grasp of a rule system, not just physics specifically: a model can correctly identify the sign or category of an effect while still silently substituting a familiar, memorized computational shortcut for the actual specified rule, and this gap only reliably surfaces once the evaluation forces genuine cross-domain application rather than single-scenario computation.

The specific technique of decomposing a benchmark into isolated stages with hard context breaks between them (a fresh session per stage, only the prior stage's final text, not its reasoning trace, passed forward) is a directly reusable methodological pattern for separating "which cognitive step failed" from "did the final answer happen to be right," and the paper's own demonstration that two frameworks can share an identical composite score (6/15) while the underlying failure concentrates on entirely different steps is a concrete, checkable illustration of why a single end-to-end pass/fail signal can hide meaningfully different capability profiles.

The specific LLM-judge failure mode documented at Decay World, a long and topically-overlapping banned-word list causing a judge to drift from literal substring matching into semantic association and fabricate quotes that do not appear in the text, is a concrete, reusable methodological warning for anyone building any lexical-exclusion check via an LLM judge (not just physics evaluation): the failure is triggered by a specific, identifiable combination of conditions (long ban list, high topical overlap between allowed and banned content, an instruction demanding literal rather than semantic matching), and a post-hoc verbatim-substring check can catch only the fabricated-citation variant of the failure, not the misclassification variant, so a dual-judge-plus-disagreement-audit architecture remains necessary even when an automated literal check is already in place.

## Verification

The paper's evaluation infrastructure is unusually rigorous for a single-author study: SHA-256-sealed, git-tagged pre-registration with a CI check that fails on any silent post-hoc edit closes off a specific, well-known class of evaluation-criteria drift; the dual-LLM-judge-plus-threshold-triggered-human-audit design is validated empirically rather than assumed to work, since the paper directly measures and reports how often each judge matches the human-audit canonical verdict on disagreement cases, revealing the judge-reliability reversal described above; and the strict stage-isolation design (fresh sessions, no carried-over reasoning trace) is a specific, verifiable mechanism for preventing a model from silently passing off one stage's capability as another's. The full release of raw prompts, responses, judge verdicts, and audit records supports independent re-analysis rather than requiring trust in the paper's own aggregation.

The main verification gap, which the paper's own Limitations section names directly and specifically, is sample size: N=5 trials per model per framework (45 trials total) is explicitly and appropriately described by the author as supporting only descriptive pattern-reading rather than any statistical claim about reliable differences between models, and the paper does not report confidence intervals or significance tests anywhere, consistent with this self-assessed scope. A second, also self-disclosed gap is that the two LLM judges (Claude and GPT) share model families with two of the three tested models (Claude Opus 4.7 and GPT-5.5), so each judge is partially scoring outputs from its own family on two of the three tested systems; only Gemini 3.1 Pro's outputs are judged entirely by cross-family judges. The paper's own mitigation, a cross-provider judge pair plus a human-audit backstop on high-disagreement cases, is a reasonable partial safeguard, but the paper explicitly states it does not separately quantify how much residual self-preference bias this leaves, so a reader cannot rule out that some of Claude's or GPT-5.5's per-trial verdicts benefit modestly from same-family judging in cases that never crossed the 25% disagreement threshold that would have triggered a human audit.

## Field context

The paper positions itself carefully against three adjacent literatures it distinguishes itself from: standard LLM physics-accuracy benchmarks (GSM8K, MATH, GPQA Diamond, PHYBench, and the paper's own explicitly-cited [reviews/2507.04766.md](2507.04766.md) ABench-Physics), which it argues share an "accuracy-as-criterion" logic that cannot distinguish genuine reasoning from pattern recall regardless of how sophisticated the perturbation or scoring scheme becomes; AI-for-science autonomy work (Coscientist, FunSearch, AI Co-Scientist, Robin, AlphaGeometry), which the paper argues always operates inside a framework humans have already fixed rather than testing whether the framework itself can be induced; and "world model" research (Ha and Schmidhuber, JEPA, Physion, Cosmos), which the paper argues addresses next-state prediction or perceptual intuition rather than the construction of an independently checkable, third-party-verifiable formal theory. It explicitly identifies two concurrent papers pursuing a closely related idea, LLM rule-discovery in non-canonical physics worlds, and distinguishes its own contribution along three specific axes (testing the full four-move chain including self-review; presenting observations in everyday language with physics terminology stripped, rather than as numerical trajectories; and including a historical framework alongside counterfactual ones to probe suspension of a trained-in refutation). Within this corpus, the closest of those two concurrent papers is [reviews/2605.26087.md](2605.26087.md) (DiscoverPhysics), which independently builds 22 simulated worlds with genuinely non-standard force laws and has models discover each world's rule through active experimentation rather than a fixed observation set; DiscoverPhysics's own headline finding, that prediction accuracy (lowest error) and explanation quality (correctly identifying the actual physics) are dissociable capacities, with GPT-5.5 achieving the best raw prediction error while Claude Opus 4.7 achieves the best explanation score and pass rate, is an independently-derived, methodologically distinct corroboration of this paper's own central qualitative-versus-quantitative asymmetry finding: across two different evaluation designs (four-stage induction/formulation/prediction/review versus active multi-round experimentation), the same general pattern recurs, that getting the qualitative physics right and getting the quantitative computation right are separable and sometimes divergent model capabilities.

## Critical discussion

The paper's methodological infrastructure, tamper-evident pre-registration, stage isolation, dual-provider judging validated against a measured human-audit baseline, and a specific, mechanistically-diagnosed LLM-judge failure mode, is a genuine strength that goes well beyond what most single-author LLM-evaluation papers attempt, and the paper's own six-point Limitations section is unusually candid, naming sample size, the single-framework-per-difficulty design, the untested-model scope, the judge-family overlap, the single-prompt-cue scope, and the three-data-point basis for the over-claim finding, all without being prompted by external review. Crediting this candor does not remove the substance of these limitations, but it does mean the paper's own claims are already appropriately hedged rather than overstated: the text consistently describes its findings as "descriptive... of patterns in the 45 trials we ran" rather than as general claims about frontier-model capability.

Two points are worth weighing directly. First, the judge-family overlap (Claude and GPT judges scoring, respectively, Claude Opus 4.7's and GPT-5.5's own outputs on two of the three tested models) is a real methodological limitation the paper discloses but does not separately quantify; the 25%-disagreement-triggered human audit provides some protection, but only for cases that actually crossed that threshold, so a reader cannot rule out mild same-family leniency in the cases that stayed below it. Second, with only one framework instantiated per intended difficulty tier, the "bottleneck migration" narrative (per-model heterogeneity at Easy, shared training-prior bottleneck at Medium, quantitative-computation bottleneck at Hard) is a coherent and well-evidenced description of these three specific frameworks, but it is not yet a tested claim about difficulty tiers in general; a different Hard-tier counterfactual world with a different structure could plausibly surface a different bottleneck, and the paper is explicit that it has not run that check.

What remains well supported after these caveats: the central qualitative-versus-quantitative dissociation (perfect directional accuracy alongside a 38% ratio-leak rate once a rule must generalize across domains) is a specific, numerically precise, and internally consistent finding across the paper's own three frameworks, and it is independently corroborated by a methodologically distinct concurrent benchmark ([reviews/2605.26087.md](2605.26087.md)) using active experimentation rather than fixed observations; the demonstration that a single composite pass rate can obscure entirely different underlying failure structures (the 6/15-versus-6/15 tie between F=mv and Aristotelian) is a clean, well-isolated illustration of a general benchmark-design point, not an artifact specific to these two frameworks; and the documented LLM-judge reliability reversal and the specific banned-token semantic-drift failure are concrete, mechanistically explained methodological contributions independent of the physics content itself.
