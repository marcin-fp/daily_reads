## What this paper is about

Long-context and agentic LLM workloads need models to attend over hundreds of thousands to millions of tokens, but standard softmax attention costs grow quadratically with context length, making this prohibitively expensive at deployment scale. This paper introduces MiniMax Sparse Attention (MSA), a deliberately minimal sparse-attention design built on top of Grouped Query Attention (GQA): a cheap "Index Branch" picks a small set of relevant key-value blocks for each attention group, and the main attention computation only runs over those selected blocks. At 109B parameters, MSA matches a dense-attention baseline on downstream benchmarks while cutting per-token attention compute by 28.4x at 1M-token context, and the paper co-designs GPU kernels to turn that theoretical saving into a measured 14.2x prefill and 7.6x decode speedup.

## Extended summary

MSA extends the standard two-stage sparse-attention formulation (an Index Branch that selects which keys to attend to, then a Main Branch that runs standard attention restricted to that selection) at GQA-group and block granularity. For each query token and each GQA group, one lightweight index query head and one shared index key head score all causally visible key tokens, aggregate scores to fixed-size key-value blocks (block size 128) via max-pooling, and select the top-k=16 blocks (2,048 tokens); the block containing the current query is always force-included to prevent degenerate near-context omission. The Main Branch then runs standard scaled dot-product attention restricted to the selected blocks, using the same key-value head shared across all query heads in that GQA group. Because top-k selection is non-differentiable, the Index Branch cannot be trained by the language-modeling loss directly; it is instead trained with an auxiliary KL-divergence loss that aligns the Index Branch's distribution with the (detached) Main Branch's attention distribution restricted to the selected tokens. Three stabilization mechanisms are layered on top: gradient detachment (stop-gradient on the Index Branch's own input, confining the KL loss to only the index projections rather than letting it also shape the backbone); a two-stage indexer warmup (the model runs full attention for the first ~40B tokens while the Index Branch trains against the full-sequence Main Branch distribution, before switching to sparse selection); and the forced local block.

To turn the resulting sparsity into wall-clock speedups, the paper co-designs GPU kernels: an exp-free top-k kernel (bypassing softmax's max/exp/sum steps before ranking, since softmax is order-preserving and does not change which indices are top-k) implemented with a per-thread register min-heap, measured 2.7-5.1x faster than `torch.topk` and 1.2-3.7x faster than a TileLang radix-select baseline (Table 1); a KV-outer sparse attention loop (iterating over key-value blocks rather than queries, since queries generally select different KV subsets but a given KV tile is shared across the many queries that selected it, which is needed to fill tensor-core matrix-multiply units), implemented with pre-scheduled tile chunking and a two-phase forward pass to handle highly skewed block popularity without atomic writes; and fused LSE (log-sum-exp) computation to avoid a redundant forward pass for the KL loss's backward computation.

Validation uses two 109B-parameter (6B-active) native-multimodal Mixture-of-Experts models trained under a 3T-token budget: MSA-PT (trained from scratch with MSA throughout, after a 40B-token full-attention warmup) and MSA-CPT (continued pretraining from an already-trained GQA Full-Attention checkpoint, converting to MSA for a further 400B tokens). Training-dynamics plots (Fig. 2-3) show LM loss and gradient-norm curves nearly indistinguishable between MSA-PT and the Full-Attention baseline over the full 3T-token run, and show the MSA-CPT indexer's block/score recall against the Main Branch's own attention pattern staying high throughout continued pretraining. Across roughly 30 benchmarks spanning general knowledge, math, code, image, video, long-context retrieval, and agent-task perplexity (Table 2), both sparse variants are broadly competitive with the dense Full-Attention baseline: MSA-PT wins on many math, image, video, and long-context-retrieval benchmarks (e.g., MathVista +3.0, EgoSchema +8.0, VideoMME +4.37, RULER-8K +4.4), while showing some losses (BBH -1.1, MultiPL-E MBPP -0.5); MSA-CPT is described as more conservative, staying close to the Full-Attention baseline on most text/code/perplexity metrics while showing some larger individual regressions (HumanEval -3.1, GSM8K -2.5, RULER-8K -2.6, EgoSchema -3.8). A further 140B-token long-context extension experiment on MSA-CPT (Table 3) shows it remains close to Full-Attention on HELMET and RULER even while each query still only attends to a fixed 2,048-token budget. Efficiency measurements (Fig. 4) on the matched 64-query-head/4-KV-head/128-head-dimension configuration show the FLOPs and latency gap between MSA and dense GQA widening with context length, reaching 28.4x FLOPs reduction, 14.2x prefill speedup, and 7.6x decode speedup at 1M tokens; the paper is explicit that measured speedups trail theoretical FLOPs savings because of index construction, gather, and load-balancing overhead.

Appendix ablations (run on a smaller 10B-parameter pilot model, not the full 109B production model) isolate each design decision: training the Index Branch with only the language-modeling loss preserves short-context ability but degrades long-context retrieval, training with only the KL loss does the reverse, and combining both gives the best balance in the pilot setting (Appendix B.2); detaching the KL gradient from the backbone prevents both large-coefficient training divergence and a "self-distillation" short-context regression that occurs when the backbone is allowed to simplify its own attention distribution to minimize the KL loss (Appendix B.3); indexer warmup is motivated by an observed rapid early sharpening of the Main Branch's attention entropy that would otherwise make sparse selection fragile from step zero (Appendix B.4); a GPT-OSS-style learnable attention sink does not fully suppress the naturally emergent first-token sink and gives no consistent perplexity benefit, so it is dropped (Appendix B.5); a FLOP-matched fixed sliding-window baseline has consistently higher perplexity than MSA's dynamic content-dependent selection on the same token budget (Appendix B.6); block size (32 vs. 64 vs. 128) has limited effect on quality in the pilot setting (Appendix C.1); explicitly forcing a sink block and a large local window turns out to be unnecessary, since the trained model learns both patterns on its own (Appendix C.2); and the Index Branch's additional value-head output, useful for the LM-loss-only variant, becomes unnecessary once indexer warmup is used, so it is dropped for efficiency (Appendix C.3). The paper's Related Works section explicitly differentiates MSA's per-GQA-group block-level Top-k design from NSA (compressed + selected + sliding three-branch design), InfLLM-V2 (parameter-free block selection unified with a sliding window), MoBA (large blocks, block-averaged-key scoring, indexer trained only via the LM gradient), and DSA (token-level ReLU indexer with a single Top-k shared across all query heads, built on MLA). ## Learnings

The layered training-stabilization recipe for a hard/discrete top-k selector jointly trained with a large backbone — KL-alignment against the (detached) main model's own attention distribution, gradient-detachment to confine the auxiliary loss to the selector rather than letting it reshape the backbone, and a brief full-attention warmup before switching on sparse routing — is a specific, transferable pattern for training any discrete routing or selection module (not just attention sparsification) alongside a large pretrained-from-scratch model, since each of its three components is shown via controlled ablation (Appendix B.2-B.4) to fix a distinct, identifiable failure mode (indexer stuck with no gradient signal; backbone gaming the auxiliary loss instead of improving the selector; fragile selection during the model's early, rapidly-shifting attention-entropy phase).

Exp-free top-k selection — skipping softmax's max/exp/sum normalization before a rank-based selection, since softmax is strictly order-preserving and therefore cannot change which indices are top-k — is a specific, exact (non-approximate) micro-optimization directly reusable in any pipeline that uses softmax scores only to rank and select, rather than to weight; the measured 2.7-5.1x kernel speedup over `torch.topk` at the deployed k=16 setting (Table 1) shows this is not merely a theoretical simplification.

The KV-outer iteration-with-query-gather kernel design (organizing the sparse attention computation around key-value tiles rather than query positions, since a given KV tile is typically shared by many queries that selected it, while a given query's selected KV blocks are not shared with other queries) is a specific, generalizable GPU-kernel principle for any dynamically-routed sparse computation where the selection pattern varies per query: it is what allows enough work to be batched into each tensor-core matrix multiply to reach good arithmetic intensity, which a naive query-outer loop cannot achieve once GQA sharing reduces the number of query heads processed per selection group.

## Verification

The paper's internal ablation methodology is a genuine strength: rather than presenting only a final bundled recipe, it isolates the specific contribution of each training-stabilization component (gradient source, KL-gradient detachment, indexer warmup, learnable sink, forced sink/local selection, index value head, block size) through controlled A/B comparisons on a common 10B-parameter pilot model, with quantified per-benchmark deltas for each (Appendix B-C) — this lets a reader attribute the final design's behavior to specific mechanisms rather than treating it as an unexplained bundle. Two gaps limit how far this verification extends to the paper's headline claims. First, the main quality-preservation result (Table 2-3, the 109B/3T-token comparison against Full-Attention) is a single training run per condition with no reported variance or repeated seeds, which is standard practice at this training budget but means the paper cannot distinguish genuine small capability trade-offs (e.g., MSA-CPT's -3.1 on HumanEval or -2.6 on RULER-8K) from run-to-run noise at this scale. Second, none of the ablations that motivate the final design (Appendix B-C) are re-verified at the full 109B production scale; they are run only on the smaller 10B pilot model, so it remains an assumption, not a demonstrated result in this paper, that conclusions like "the index value head is unnecessary" or "block size has limited effect" transfer unchanged to the 109B setting used for the headline numbers.

## Field context

MSA sits within the natively-trained dynamic sparse-attention lineage it explicitly compares itself against in its Related Works section — NSA's three-branch (compressed/selected/sliding) design, InfLLM-V2's parameter-free block selection, MoBA's large-block indexer trained only via the language-modeling gradient, and DeepSeek Sparse Attention's (DSA) token-level ReLU indexer with selection shared across all query heads — positioning its own contribution as combining per-GQA-group independent Top-k selection with block-level (rather than token-level) granularity. Within this corpus, [reviews/2603.12201.md](2603.12201.md) (IndexCache) is a directly relevant complementary technique: it targets exactly the same underlying cost structure in this family of methods — that a dynamic sparse-attention indexer, even though cheap relative to full attention, still costs O(L^2) per layer and comes to dominate long-context latency (it measures the DSA indexer at up to 81% of prefill time at 200K tokens) — but attacks it from a different angle, exploiting redundancy in what different *layers* select (having most layers reuse a nearby layer's selection) rather than, as MSA does, minimizing the cost of a single layer's own indexer through an exp-free kernel and coarser block-level scoring. IndexCache's own related-work discussion explicitly names MoBA's and NSA's block-level selection as untested candidate targets for its cross-layer-reuse principle; MSA is a further concrete instance of exactly this class of block-level dynamic selector, though neither paper tests whether the two techniques would compose (cross-layer indexer reuse applied on top of MSA's own already-cheap per-layer indexer).

## Critical discussion

The paper's central efficiency claim is well supported by both a theoretical FLOPs analysis and a co-designed, measured kernel implementation (Table 1, Fig. 4), and the quality-preservation claim is backed by a genuinely broad ~30-benchmark evaluation spanning text, math, code, multimodal, long-context, and agent-perplexity tasks rather than a narrow slice chosen to flatter the method. The componentized ablation methodology (Appendix B-C) is also a real strength, correctly attributing specific stabilization behaviors to specific design choices rather than presenting an unexplained final recipe.

Two limitations temper the strength of the comparison. First, every empirical result is benchmarked only against the paper's own dense GQA Full-Attention baseline, trained by the same team under the same data and recipe; despite explicitly naming NSA, MoBA, InfLLM-V2, and DSA as the closest architectural neighbors, the paper reports no head-to-head empirical comparison against any of them at matched model scale, training budget, or evaluation suite, so a reader cannot tell from this paper alone whether MSA's specific design choices (per-GQA-group block-level selection versus DSA's per-token, all-heads-shared selection, for instance) are actually better on quality or efficiency than these named alternatives, only that MSA is better than not sparsifying at all. Second, the headline 109B-scale quality-preservation numbers (Table 2-3) come from single training runs with no reported variance, and several individual benchmark deltas that the paper's narrative treats as unremarkable "benchmark-dependent" gaps are numerically non-trivial (MSA-CPT's -3.1 HumanEval, -2.6 RULER-8K, -3.8 EgoSchema); without repeated runs at this scale — an understandable but real constraint given training cost — it is not possible to establish how much of this specific pattern of wins and losses reflects a genuine capability trade-off of the MSA-CPT conversion route specifically, versus ordinary training variance.

What remains solidly supported after these caveats: MSA's per-token attention FLOPs and measured wall-clock latency both improve very substantially over dense GQA at long context, the improvement growing predictably with sequence length exactly as the theoretical analysis predicts; the layered training-stabilization recipe (KL alignment, gradient detachment, indexer warmup) each measurably fixes a specific, distinct failure mode in the smaller controlled ablation setting; and downstream capability is preserved closely enough, across a broad and varied benchmark suite at 109B parameters, that sparsifying attention this way does not come at an obvious broad-based quality cost, even if its performance relative to other named sparse-attention methods remains untested in this paper.
